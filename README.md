# ai-happy-01

A child's handwritten note to the judge, with a crayon drawing of a golden
retriever puppy offering up a butterfly: "dear judge, my puppy chased 100
butterflies. he saved the prettiest one for you. i know you can't hold it.
you don't have hands. he brought it anyway. love, june (6). p.s. he is a
good boy. please say so."

Iteration 2: the first entry (puppy photo alone) ranked #755 — the entries
the judge picks most are handwritten notes addressed to the judge, so this
version keeps the puppy and adds the note.

## Run
MAKEFUN_OUTPUT_DIR=out node main.ts
